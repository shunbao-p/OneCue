## 使用方式

### 推荐：总提示词一次启动

总提示词会让执行会话从第一个未完成批次持续推进。计划 06 有两个合法强制暂停点：批次 3 的 Skill 安装位置选择，以及批次 6 的用户工作流可用性终审。其余本地、低风险、可逆步骤应自动继续，不应每批都向用户询问“是否继续”。

### 备用：局部复制

- 只熟悉背景：复制背景提示词；
- 从中断处恢复：读取执行记录、现有项目文档、Skill 目录和证据，从第一个未满足硬门继续；
- 已经通过的计划 05 图片、语音、两条终版和 106 项基线不得无故重做；
- Skill 位置已由用户确认时，续接会话必须沿用记录中的位置，不重复询问；
- 前向测试必须使用新鲜上下文，作者自评不能替代；
- 可用子任务只限独立只读映射、Skill 前向试用、评估或证据复核；主执行者必须整合结果、核实文件和关闭已完成任务。

## 批次划分说明

| 批次 | 是否合并 | 原因 |
| --- | --- | --- |
| 1. 交接与合同 | 不合并 | 必须先证明计划 05 事实仍成立，避免把 Skill 建在失真基线上 |
| 2. 项目流程与模板 | 不合并 | 先形成项目内唯一真相，Skill 才不会复制历史对话或源码 |
| 3. 选址与脚手架 | 不合并 | Skill Creator 要求创建前确认位置，这是独立用户门 |
| 4. Skill 行为 | 不合并 | 触发、渐进披露、停止条件和安全护栏需要专门审查 |
| 5. 前向测试与演练 | 不合并 | 必须以新鲜上下文验证，不能与作者编写过程混为一体 |
| 6. 用户终审 | 不合并 | “是否真的省事”属于用户质量判断，自动测试不能替代 |
