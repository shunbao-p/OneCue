【包B】语音引擎包 使用手册

本地离线 TTS，把文字合成为梁文峰音色语音，与【包A】视频引擎配合使用。

一、硬件要求（重要）

快速版（dots-tts-mf）
约 8GB 显存 即可
速度约 2.5 倍快，推荐大多数人先用这个
质量版（dots-tts-soar）
建议 10GB 以上显存
克隆相似度最高、音质最好，但更慢更吃显存

必须有 NVIDIA 显卡 且支持 CUDA。没有独显或显存不够 → 本包跑不了，但【包A】视频引擎仍可正常出片。

二、启动步骤

  1. 解压本包到一个纯英文路径（例如 D:\语音引擎包），避免路径含中文/空格。
  2. 双击 启动-快速版.bat 或 启动-质量版.bat。
    • 先弹出黑窗口设置运行环境；
    • 然后加载模型（首次 1~3 分钟，请勿关闭窗口）；
    • 完成后自动打开本地网页 http://127.0.0.1:7860。
  3. 在网页里输入文字即可试听合成效果。

三、与【包A】视频引擎联动

  1. 确认本包已启动（本地网页能打开）。
  2. 打开【包A】视频引擎，双击 ②连接语音引擎.bat（找不到时可把本包文件夹直接拖到该 bat 上）。
  3. 回到【包A】网页刷新，配音/音色里出现“梁文峰”等音色。完成
  4. 视频生成时勾选“配音”，即可自动生成带梁文峰声音的成片。

四、文件缺失怎么办

若启动器提示“文件不完整，请重新解压”，说明压缩包没传完整：请向发布者重新要一份完整压缩包，解压整个文件夹后再试。
本包不做自动下载，以免下载到不完整或被篡改的文件。

五、排错

  • 显存不足：换“快速版”；仍报错则本机显卡不满足要求。
  • 中文用户名导致 Triton 报错：本启动器已把缓存改到包内；若仍报 torch compile 错误，可打开 bat 把 :: set TORCH_COMPILE_DISABLE=1 前的 :: 删掉。
  • 端口被占用：默认 7860，关闭占用程序后重试。
  • 想彻底重来：关闭黑窗口，删掉包内 .triton_cache / .inductor_cache / tmp 再启动。

六、隐私

包内不含任何私人录音与文稿，所有合成都在你本机完成，完全离线、不联网、不上传数据。
